# AI Agent Playground

Одностраничное приложение на Node.js для общения с моделью через настраиваемый API и безопасным инструментом терминала.

## Возможности

- полноэкранный тёмный UI с настраиваемой панелью и сохранением параметров между сессиями;
- визуализация "мыслей" модели (режим think) прямо в ленте диалога;
- поддержка режима размышлений `think`;
- история диалога хранится между запросами (включая ответы инструмента);
- встроенный инструмент `terminal` выполняет команды только внутри директории `sandbox` с защитой от выхода за её пределы;
- проксирование запросов к произвольному API, совместимому с форматом, показанным в примерах;
- автоматическое выполнение дополнительных шагов при запросе модели инструментов.
- встроенные системные инструкции для модели усиливают роль агента-разработчика, пользователь может добавить свои.

## Запуск в режиме разработки

```bash
npm install
npm run dev
```

Приложение будет доступно на `http://localhost:8000`.

## Сборка и запуск через Docker

См. [Dockerfile](./Dockerfile) для запуска на базе Ubuntu.

## Структура проекта

- `src/server.js` — Express-сервер и прокси к модели;
- `public/` — статические ресурсы интерфейса;
- `sandbox/` — директория, доступная инструменту `terminal`;
- `README.md` — документация.

## Переменные окружения

- `PORT` — порт сервера (по умолчанию `8000`);
- `DEFAULT_MODEL_ENDPOINT` — базовый эндпоинт модели;
- `TERMINAL_TIMEOUT_MS` — таймаут работы терминала (мс);
- `TERMINAL_MAX_BUFFER` — максимальный буфер вывода терминала.

## Безопасность терминала

Каждая команда проверяется и выполняется с рабочим каталогом `sandbox`. Попытки перейти за пределы директории блокируются.
